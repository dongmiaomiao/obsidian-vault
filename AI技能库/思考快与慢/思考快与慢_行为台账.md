# 《非暴力沟通》行为台账

## 一、什么时候该用这本书的方法
- 和伴侣、家人、朋友吵架，你觉得他完全不理解你
- 需要给同事或下属提出批评，但不想撕破脸
- 有人对你发脾气，你不知道怎么回应，要么忍要么爆发
- 你想请别人帮忙，但不知道怎么开口才不会被拒绝
- 你总是在心里骂自己“你怎么这么蠢”，然后陷入自责
- 想感谢一个人，但“谢谢”两个字说出来总觉得不够
- 在关系中感到对方总是命令你，你想说“不”又怕破坏关系

## 二、这本书最核心的三件事

### 第一件事：日常说话很多是“隐形暴力”
不是只有骂人打人才叫暴力。以下几种说话方式都是：
- **评判**：“你就是个自私的人”
- **比较**：“你看看别人家的男朋友”
- **推卸责任**：“没办法，我必须这么做”
- **威胁**：“你不答应我就分手”
这些方式的共同点：把焦点从“我需要什么”转移成了“你是错的”。

### 第二件事：沟通的目的不是赢，是连接
非暴力沟通假设：所有冲突背后，都是双方的需要没有被满足。
所以目标不是说服对方，而是让双方的需要都被看见。
一旦需要被看见，解决方案会自己长出来。

### 第三件事：四个步骤，是公式也是护身符
- 说观察：“我看到……”
- 说感受：“我感到……”
- 说需要：“因为我需要……”
- 说请求：“你愿意……吗？”
每一步都跳过了指责，直接通往问题的核心。

## 三、你可以照着做的步骤

### 有人对你说了一句让你很生气的话，这样回应
1. **先别说话，深呼吸3次**。你的第一反应会想攻击，忍住。
2. **在心里翻译他**：把他的指责翻译成“他有什么感受？什么需要没被满足？”
3. **说出来验证**：“你是感到[感受]，因为你希望[需要]，对吗？”
4. **等他确认**。如果他纠正你，重复步骤2-3。
5. **轮到你表达**：说出你的观察、感受、需要、请求。

### 你想对某人说一句难听的话之前，这样处理自己
1. **停**：把手从键盘或嘴上拿开。
2. **找感受**：我现在是什么感受？（愤怒？委屈？失望？）
3. **找需要**：这个感受背后，我什么需要没被满足？
4. **说出来**：“我感到[感受]，因为我需要[需要]，你愿意[请求]吗？”

### 当你在心里骂自己时
- 不要说：“我怎么又搞砸了，我真是个废物。”
- 换成问自己：“我做了什么具体的事？（观察）我现在什么感受？（感受）我的什么需要在抗议？（需要）”
- 把对自己的审判，变成对自己的理解。

### 感谢别人时，不再只说“谢谢”
- 说清楚三件事：你做了什么具体的事 + 满足了我什么需要 + 我产生了什么感受
- 比如：“昨天你帮我改PPT到凌晨两点（事），因为你的帮忙我准时交了方案（需要），我感觉自己不是一个人在扛着（感受）。”

## 四、常见的错误用法
- **把观察变成伪装好的评判**：“我看到你很自私”（这不是观察，是评判，只是加了“我看到”）
- **请求变命令**：嘴上说“你愿意…”，但对方如果说“不”，你就甩脸色。这不是请求，是软性命令。
- **套公式变成机械操作**：没有真正去理解对方，只是走流程，会让对方觉得你在套路他。
- **只对外用，不对内用**：对别人非暴力，对自己继续暴力。这不是完整的练习。
- **在对方完全关闭沟通时强推**：对方说“我不想谈”的时候，先尊重边界，不要强行走流程。

## 五、什么时候不能用这个方法
- 对方处于极度失控状态（比如暴力行为、完全失控的咆哮）。此时先确保安全，不是沟通的时机。
- 你处于极度的情绪崩溃中。先找别人照顾自己，不要硬撑着去“非暴力沟通”。
- 商业谈判或法律场合，如果对方完全没有意愿“连接”，你的单向非暴力沟通可能变成单方面退让。
- 你只是想要对方听你的，而不是真的想理解对方。如果是这样，诚实地承认自己还没准备好。

## 六、这个方法的局限性
- 需要对方至少有一点点沟通的意愿。如果对方完全拒绝连接，非暴力沟通只能帮你自己的情绪，不能改变对方。
- 需要持续练习，不是看一遍就能做到。第一次用会觉得很别扭，像在说一种外语。
- 它不解决“权力不对等”的结构性问题，它解决的是“人在对等条件下如何连接”。
