把上下文、缓存和成本从技巧提升为系统设计能力。

本章从系统层面总结前面的 token 和上下文内容。读者要把项目文档、规则、知识库、提示词和日志都看

成上下文工程的一部分。缓存友好不是单个技巧，而是稳定资料结构和减少无效变动的结果。

• 理解“上下文工程、缓存和成本工程”在 Claude Code 学习路线中的位置。

• 能根据检查清单判断任务是否真正完成。
