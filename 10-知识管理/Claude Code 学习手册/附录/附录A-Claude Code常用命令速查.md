附录 A：Claude Code 常用命令速查本附录用于快速查找日常使用命令。具体命令可能随 Claude Code 版本变化，执行前应以官方文档和本机

claude --help 为准。

启动与目录

# Windows PowerShell

Set-Location "D:\your-project"

claude

# macOS / Linux

cd ~/your-project

claude 常用检查

# Windows PowerShell

claude --help

claude --version

# macOS / Linux

claude --help

claude --version

推荐使用习惯

• 在项目根目录启动。

• 修改前先让 Claude Code 检查 Git 状态。

• 高风险命令执行前要求它解释影响。

• 所有修复都要求给出验证命令。
