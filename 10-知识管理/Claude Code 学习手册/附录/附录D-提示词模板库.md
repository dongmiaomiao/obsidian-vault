附录 D：提示词模板库

Bug 修复提示词

目标：修复以下 Bug。

范围：只允许修改与 Bug 直接相关的文件。

步骤：先读取错误日志，再提出假设，再写回归测试，最后修改代码。

限制：不要做无关重构。

输出：原因、修改点、验证命令、剩余风险。

代码审查提示词

请以代码审查员身份审查当前 diff。

优先级：Bug、行为回归、安全风险、测试缺口、可维护性。

输出格式：严重级别、文件路径、问题、建议修复方式。

Opus 4.7 深度分析提示词

这是一个高风险复杂工程问题。请先列出你需要确认的事实，再分层分析可能原因。

要求：给出假设、证据、反例、验证步骤和不确定性。

不要直接修改代码，先输出计划等待确认。Claude Code 学习手册
