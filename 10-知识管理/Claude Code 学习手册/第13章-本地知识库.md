命令示例：Windows PowerShell 为主，macOS/Linux 对照。

本章导读

帮助读者建立给 Claude Code 使用的本地知识库，把经验、决策和项目背景沉淀下来。

本章把本地知识库定位为“可搜索、可引用、可维护”的长期上下文，而不是随手堆文件。读者要学会为每

篇知识写摘要、关键词、适用场景，并让 Claude Code 通过索引找到资料。

学习目标

• 理解“本地知识库”在 Claude Code 学习路线中的位置。

• 能把本章知识转化为一个可交给 Claude Code 执行的小任务。

• 能用 Python 示例完成本章案例，并知道如何迁移到其他语言项目。

• 能根据检查清单判断任务是否真正完成。
