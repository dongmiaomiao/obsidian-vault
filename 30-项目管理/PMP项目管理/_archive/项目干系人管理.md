# PMP 干系人管理

> 核心问题：如何识别并管理相关方（干系人），让他们朝着有利于项目的方向参与？

## 四大过程总览

| 过程 | 过程组 | 做什么 | 关键输出 |
| --- | --- | --- | --- |
| 识别相关方 | 启动 | 分析 + 分组（排序），人分三六九等 | 相关方登记册 |
| 规划相关方参与 | 规划 | 分析参与态度，对比期望程度，定管理策略 | 相关方参与计划 |
| 管理相关方参与 | 执行 | 持续了解期望与需求，解决人际冲突 | 变更请求 |
| 监督相关方参与 | 监控 | 跟踪相关方变化，判断是否调整策略 | 工作绩效信息 |

## 与沟通管理的联动（三步骤）

**识别相关方 → 规划相关方参与（定策略）→ 规划沟通管理**

先识别相关方，再分析他的态度、立场，定合适的管理策略（不同人群策略不同），有了策略才能更好地规划如何有效沟通，所以下一步是规划沟通管理。**不要上来就沟通。**

## 1. 识别相关方

核心两个词：**分析 + 分组（排序）**——事分轻重缓急，人分三六九等。

- 分析相关方的权力、作用、影响力、利益、兴趣爱好（姓名、性别等公开信息直接登记，不用分析）。
- 根据分析结果分组、排序，确定优先级。

工具与技术：

- **相关方分析**：分析权力、利益、作用、爱好、影响，产出相关方清单及各类信息，目的是更好地分组、排序。
- **权力/利益方格**（见下）。
- **相关方立方体**：在权力/利益方格基础上增加其他维度变三维，改良形式，有助于制定更精准的管理策略。
- **凸显模型**：权力（官大官小）+ 紧迫性（急不急）+ 合法性（参与是否被认可）三个维度——三者皆有 = 高显著人群（重点管理）；有两个 = 中显著；只有一个 = 低显著；一个都没有 = 非相关方。适合复杂场景下对干系人分组排序。

输出：**相关方登记册**（发现啥记录啥）：

1. **身份信息**：姓名、组织、职位、地点、联系方式、项目角色。
2. **评估信息**：需求、期望、影响力分析的结果。
3. **相关方分类**：分组、排序、优先级（谁重要谁不重要）。

### 权力/利益方格

权力 = 官大官小；利益 = 感不感兴趣。两者排列组合决定不同的管理策略：

| 权力 | 利益 | 策略 |
| --- | --- | --- |
| 高 | 高 | 重点管理（优先级最高） |
| 高 | 低 | 令其满意（不感兴趣） |
| 低 | 高 | 随时告知（做好信息传递，可能是一线最终用户） |
| 低 | 低 | 监督（监督其属性有没有变化，及时调整策略） |

## 2. 规划相关方参与

分析相关方**目前的参与程度**，对比**期望达到的参与程度**，制定管理策略。

- 现状 vs 期望：现在不知情 → 希望他支持；现在反对 → 希望他支持；现在口头支持 → 希望他有实际行动。

工具与技术：

- **相关方参与度评估矩阵**：五种参与水平——① 不了解（不知情）；② 抵制（反对）；③ 中立（不表态）；④ 支持（口头，了解项目及影响）；⑤ 领导（行动，积极参与推动项目成功）。

输出：**相关方参与计划**（干系人管理策略）。

## 3. 管理相关方参与

持续了解相关方的期望与需求，解决人与人之间的冲突。

## 4. 监督相关方参与

跟踪相关方有没有变化，判断是否调整管理策略。

## 关键原则

- 尽早识别相关方并引导参与；尽量全部识别，尽量不要遗漏。
- 人一旦有了变化，就开展「识别相关方 → 规划相关方参与 → 规划沟通管理」。
- 干系人绩效域：识别干系人 → 分析干系人 → 理解干系人，对应到参与度。
- 定位区分：「我不听、不愿听你解释」是**态度问题**，定位到相关方管理；「我听不清楚」是**信息传递问题**，定位到沟通。
