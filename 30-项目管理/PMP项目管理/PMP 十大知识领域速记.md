# PMP 十大知识领域速记

> 按 PMBOK 第 6 版「十大知识领域」整理。

## 一、项目整合管理

**过程**：制定项目章程 → 制定项目管理计划 → 指导与管理项目工作 → 管理项目知识 → 监控项目工作 → 实施整体变更控制 → 结束项目或阶段

整合管理负责组织协调，把 10 个知识领域统筹起来：

- **制定项目管理计划**：根据项目目标制定切实可行的行动计划、作战方案。
- **指导与管理项目工作**：按计划干活，得到成果。
- **监控项目工作**：跟踪工作的绩效表现。
- **实施整体变更控制**：确保所有变更受控。
- **结束项目或阶段**：验收通过后，结束项目中的某个阶段。

## 二、项目范围管理

**过程**：规划范围管理 → 收集需求 → 定义范围 → 创建 WBS → 确认范围 → 控制范围

核心是「做且仅做」——把范围的边界约定好，既完成范围内的事，也仅完成范围内的事。

- **收集需求**：产出需求文件。
- **定义范围**：写范围说明书。
- **创建 WBS**：得到工作分解结构（WBS）与 WBS 词典。
- **范围基准**：把范围说明书 + WBS + WBS 词典打包，交给有权利的关键干系人审批，得到范围基准。

## 三、项目进度管理

**过程**：规划进度管理 → 定义活动 → 排列活动顺序 → 估算活动持续时间 → 制定进度计划 → 控制进度

关注「时间够不够、能不能按时交付」，核心产出是详细的进度计划（甘特图）。

- **定义活动**：找到范围基准最底层的工作包，拆解出完成它们所需的具体活动，得到活动清单。
- **排列活动顺序**：确定先干啥后干啥、串行还是并行。通过紧前关系绘图法（PDM）、依赖关系整合、提前量与滞后量，转化为网络图。
- **估算活动持续时间**：先根据资源可用性提出资源需求，再估算时长，可用类比估算、参数估算、自下而上估算等方法。
- **制定进度计划**：把活动清单、逻辑关系、资源需求、持续时间输入软件，形成甘特图；再用关键路径法找到工期，做资源优化；无法按期交付时考虑进度压缩，形成可行的进度基准，交关键干系人审批。

## 四、项目成本管理

**过程**：规划成本管理 → 估算成本 → 制定预算 → 控制成本

关注「钱够不够花」，能否在章程给定的宏观预算内完成工作。

- **估算成本**：在活动维度，依据资源需求与持续时间（人、天不同，成本不同），用各种估算方法算出活动成本。
- **制定预算**：从工作包、控制账户到整个项目逐层汇总，考虑已知风险与未知风险：
  - 成本 + 应急储备 = **成本基准**
  - 成本基准 + 管理储备 = **资金需求（项目预算）**
- 交关键干系人审批。

## 五、项目质量管理

**过程**：规划质量管理 → 管理质量 → 控制质量

好的质量是规划设计出来的，预防为主。

- **控制质量**：完成成果后先自己做检查、做测试，通过后再验收、移交，可减少外部失败成本（但无法从源头防止错误发生）。
- **管理质量**（更关注过程质量，能有效减少缺陷的发生）：
  1. **质量保证（QA）**：确保过程符合既定政策、标准、流程、规范，干活合规。
  2. **过程改进**：关注降本增效，运用 PDCA、六西格玛等成熟体系。
  3. **产品设计**：设计时考虑产品的方方面面，设计出成熟的产品。
- **规划质量管理**：分析质量政策与标准要求，规划如何做质保、做质控，让每个人理解并形成企业文化——多、快、好、省。

## 六、项目资源管理

**过程**：规划资源管理 → 估算活动资源 → 获取资源 → 建设团队 → 管理团队 → 控制资源

- **规划资源管理**：定组织架构与责任分配。三个和尚没水喝——必须各司其职，明确个人/团队目标、工作职责与权限。
- **获取资源**：按进度计划与资源需求拿到资源，三大渠道：
  1. 预分派（职能经理，优质资源）
  2. 谈判（与其他项目经理协调稀缺资源）
  3. 招募/采购（供应商）
- **建设团队**：遵循塔克曼发展模型——形成、震荡、规范、成熟、解散，不同阶段采取不同管理方法与领导力风格。
- **管理团队**：处理人与人之间的冲突。人的问题 = 能力 + 态度，本着治病救人的原则，该帮助的帮助、该培训的培训、该指导的指导、该启发的启发，发挥服务型领导。
- **控制资源**：保证资源不浪费。

## 七、项目沟通管理

**过程**：规划沟通管理 → 管理沟通 → 监督沟通

沟通管理侧重**信息的传递**，确保信息在正确的时间、地点，以正确的方式传达给正确的受众，并产生正确的影响。

- **规划沟通管理**：制定沟通管理计划，约定沟通的方方面面。工具：沟通需求分析（对症下药）、沟通风格评估（分析沟通偏好）。
- **管理沟通**：执行既定的沟通计划，确保信息按计划收集、生成、发布、传输、存储（发通知、开会、写文档）。输出**项目沟通记录**（留痕，避免口说无凭）。
- **监督沟通**：检查沟通效果，优化改进，防止低价值沟通浪费人财物（沟通需要资源、时间，产生成本）。

### 沟通管理计划内容

1. 相关方的沟通需求
2. 需沟通的信息（语言、形式、内容、详细程度）
3. 上报步骤（问题升级，不越级）
4. 发布信息的原因（说明价值意义）
5. 时限和频率
6. 确认收到或做出回应
7. 负责沟通相关人员
8. 负责授权保密信息发布的人员

### 有效沟通要点

- 正式书面是最常用的方式。
- 会议管理：会前准备议题、议程、目的、时间、地点、参会人（重要会议提前发资料）→ 会中按议程 → 会后形成会议纪要。
- 非正式沟通：电子邮件、社交媒体、临时讨论。
- 文化差异：具备文化意识，减少误解冲突。
- 有效沟通属性：目的明确；了解接收方需求与偏好；监督衡量沟通效果。

## 八、项目风险管理

**过程**：规划风险管理 → 识别风险 → 实施定性风险分析 → 实施定量风险分析 → 规划风险应对 → 实施风险应对 → 监督风险

- **规划风险管理**：产出概率影响矩阵与风险等级定义——了解干系人风险偏好，转为临界值，再分区间，形成明确的评级依据。
- **识别风险**：找风险。
- **实施定性风险分析**：对单一风险排优先级，说清排序依据（重要性、优先级）。
- **规划风险应对**：威胁应对——规避、减轻、转移、接受、上报；机会应对——开拓、提高、分享、接受。
- **实施风险应对**：把应对措施落实到位。

## 九、项目采购管理

**过程**：规划采购管理 → 实施采购 → 控制采购

关注「买东西」：

- **规划采购管理**：写招标文件、采购工作说明书（SOW）、供方选择标准、预算。
- **实施采购**：招标 → 投标 → 开标 → 评标 → 定标（授标/中标）→ 签约，即选卖方、签合同。
- **控制采购**：检查供应商的工作与成果，跟踪绩效表现，钱货两清、交易关闭。

## 十、项目相关方管理

**过程**：识别相关方 → 规划相关方参与 → 管理相关方参与 → 监督相关方参与

干系人管理关注干系人对项目的**态度/参与度**；沟通管理关注**信息传递**。沟通之前先分析干系人的态度（不想听、不愿听还是支持），据此定策略，目的是把信息有效传达。

- **识别相关方**：找干系人（看项目涉及哪些情景、人群），核心是「分析 + 分组」——事分轻重缓急，人分三六九等。分析权力、影响、兴趣、作用、爱好等，据此分组排序。输出**相关方登记册**：
  1. 身份信息（姓名、组织、职位、地点、联系方式、项目角色）
  2. 评估信息（需求、期望、影响力等分析结果）
  3. 相关方分类（分组、排序、优先级）
- **规划相关方参与**：分析干系人当前的参与度（五级：不知晓、抵制、中立、支持、领导），对比期望达到的参与程度，制定管理策略。工具：相关方参与度评估矩阵。输出：**相关方参与计划**。
- **管理相关方参与**（执行过程组）：持续了解干系人期望与需求，解决人与人之间的冲突。
- **监督相关方参与**（监控过程组）：跟踪干系人变化，判断是否调整策略，尽早识别并引导相关方参与。

> 顺序逻辑：识别相关方 → 规划相关方参与（定策略）→ 规划沟通管理（据策略定传播方式）。
