# PMP 知识点速记

> 备考期间的零散考点整理：生命周期、目标与制约、组合与集、优先级、团队、需求、敏捷实践、图表、过程组等。

## 一、生命周期类型

| 类型 | 特点 | 适用场景 |
|---|---|---|
| 预测型（瀑布） | 充分了解产品，一次性交付 | 需求明确、能一次搞定 |
| 迭代型 | 循环交付、渐进增加 | 技术不确定 |
| 增量型 | 逐步增加产品功能 | 范围不明确 |
| 适应型（敏捷） | 快速迭代，周期通常 2–4 周 | 目标不明确、需快速响应市场与反馈 |

**增量 vs 迭代**

- 增量：增加产品的功能——先做一块，再做一块，逐步做全。
- 迭代：循环。备考 PMP 的过程就是循环：每天「听课 → 看书 → 做题」，一章学完再循环到下一章，不断重复。
- 增量迭代：重复地想办法增加产品功能，边做边循环。

**迭代型/增量型 vs 适应型**

- 两者本质一样：都是循环、都在增加功能。
- 区别在迭代周期长短：适应型 < 4 周；迭代和增量通常 > 4 周（2 个月、4 个月、6 个月……）。
- 明确能一次搞定 → 用预测型；需要稳扎稳打、定期推出新功能、迭代周期较长 → 用迭代和增量。

## 二、项目目标：多快好省

- 范围目标：要做出什么样的产品/服务/成果，具备哪些功能。
- 进度目标：多长时间做完。
- 成本目标：花多少钱、在多少预算内完成。
- 质量目标：达到什么样的质量标准和要求。

四个目标常被概括为**多快好省**，对标范围、进度、成本、质量四大知识领域。

> 中间是**范围**，旁边是约束性目标（时间、成本、质量），呈三角关系。

## 三、六大制约因素

范围、进度、成本、质量、资源、风险——任何一个因素变化，都会引起其他因素的连锁反应：

- 范围做多 → 需要更多时间 → 影响进度；
- 想缩短工期 → 增加资源 → 成本上升；
- 投入的资源水平参差 → 引发质量问题 → 又影响进度；
- 种种不确定性 → 带来风险。

所以要综合考虑，任何一个因素的变化都要权衡它对其他因素的影响。

## 四、项目组合、项目集、运营

- 定愿景、使命、价值观 → 定战略计划。
- 战略计划敲定后，事情分为两类：**项目** 和 **运营**。
  - 项目：临时性、独特性，做完就结束。
  - 运营：持续、重复（如每天买原料、生产口罩、销售）。
- **项目集**：多项目管理，项目之间存在依赖关系（尤其成果上的依赖），关注如何协调好、一次做到位。
- **项目组合**：要做的事情很多，关注如何分配好人、财、物。

## 五、优先级：艾森豪威尔矩阵

按两个属性判断：**重要程度** 和 **紧急程度**。

| | 紧急 | 不紧急 |
|---|---|---|
| **重要** | 马上做 | 有规划地做 |
| **不重要** | 授权别人处理（事急，需马上响应） | — |

## 六、风险与变更

- 项目**开始**：风险最大、变更代价最小。
- 项目**后期**：变更代价大、风险变小。
- 确定目标，有助于提高项目成功的可能性。
- 发现什么，就记录什么。

> **渐进明晰 ≠ 范围蔓延**
>
> - 渐进明晰：从目标到范围到各种计划，从高层级到底层级不断丰富、细化——这是正常且好的特征。
> - 范围蔓延：失去控制、未经管理的范围变化——这是不好的现象。
> - 变更本身不可怕，可怕的是变更没人管：没有综合考虑对成本、进度、质量、沟通、采购的影响，没有做好综合分析和权衡就草率决策。所以关键在于**变更管理**。

## 七、团队与资源

- **获取资源**：拿资源。
- **建设团队**：打鸡血（提升能力与士气）。
- **管理团队**：解决冲突。
- **知识管理**：有人离职时，做好知识转移（管理知识库）、工作交接有文档，避免知识流失。

## 八、成本类型

- **直接成本**：培训等只用于专用地方，属于项目直接成本。
- **间接成本**：培训的技能其他项目也用得上，由公司出、分摊管理费。

## 九、领导力

领导力就是让别人有主动性——以身作则。

## 十、需求收集方法

- 需求不确定 → **原型法**（做出原型给用户看）。
- 需求表述不清 → **观察法**（观察用户实际工作）。
- 技术不确定 → 用**迭代**解决。
- 范围不明确 → 用**增量**解决。
- **亲和图**：对需求/想法做分组归类。
- **名义小组技术**：对需求做排序。

## 十一、敏捷实践

**四大会议（固定节奏的沟通）**

- 参与规划 → 迭代规划会
- 参与验收 → 迭代评审会
- 参与改进 → 回顾会
- 持续了解情况 → 每日站会

**其他实践**

- **停车场**（临时挂起区）：把偏离主题的议题暂时挂起，保持会议正常、不被打断。
- **西瓜项目**（时效性）：及时跟踪进展（外表绿、里面红）。
- **看板**：可视化工作流。
- **技术债务**：为短期效应选择易于实现的方案，长远带来消极影响。快速响应需求，非最优的临时性解决方案。重构。


## 十二、可视化图表

- **燃尽图**：剩余工作量，直观展示迭代速度。
- **燃起图**：整个项目的总故事点数，展示迭代过程中范围的变化。
- **散点图**：判断两个变量是否存在联系。
- 燃尽图、燃起图用于实时测量，帮助团队了解工作能否按时完成。

## 十三、五大过程组

1. **启动**：授权项目经理开始项目或某个阶段。
2. **规划**：制定当前阶段的行动方案。
3. **执行**：按方案、计划去干活，完成项目工作。
4. **监控**：① 绩效（工作进展怎么样）；② 变更（管好过程中的各种变化）。
5. **收尾**：结束项目或项目中的某个阶段。
